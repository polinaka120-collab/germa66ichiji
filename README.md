# GERMA 66 — Ичиджи

Мобильный PWA-чат для браузера iPhone и Android. История хранится в `localStorage` на устройстве. Ответы генерируются через OpenAI Responses API; ключ хранится только на сервере.

## Что нужно
- Node.js 18 или новее
- API-ключ OpenAI, настроенный владельцем/взрослым, который отвечает за аккаунт и возможные расходы

## Запуск локально
1. Распакуй архив.
2. Скопируй `.env.example` в `.env`.
3. В `.env` укажи `OPENAI_API_KEY=...`. Ключ не публикуй и не вставляй в браузер.
4. В терминале из папки проекта выполни `npm start`.
5. Открой `http://localhost:3000`.

Проект не требует `npm install`: используются встроенные модули Node.js и `fetch`.

## Установка на телефон
Для установки PWA нужен HTTPS-хостинг:
- Android: открой опубликованный HTTPS-адрес в Chrome → меню → «Установить приложение» / «Добавить на главный экран».
- iPhone: открой HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».

Для публикации нужен сервер, который запускает `node server.js`, и переменные окружения `OPENAI_API_KEY`, при необходимости `OPENAI_MODEL` и `PORT`. Не размещай `.env` в публичной папке и не отправляй API-ключ в клиент.

## Настройки и ограничения
- В меню можно проверить соединение, экспортировать или очистить историю.
- Браузер хранит до 100 последних сообщений; сервер получает последние 24 сообщения для контекста.
- Это фанатский проект, неофициально связанный с One Piece. Персонаж может ошибаться или интерпретировать канон, это не энциклопедия.
- API может тарифицироваться отдельно от подписки ChatGPT. Перед использованием проверь условия и стоимость у провайдера. Несовершеннолетнему не следует самостоятельно создавать платёжный аккаунт или настраивать оплату: это должен делать родитель/опекун.
